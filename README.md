# AI Registry — OpenAI (Inferred)

> **Inferred vendor repository.** This repo is maintained by the [AI Registry](https://github.com/eclipsefdn-ai-registry/ai-registry-core) project, not by OpenAI. It pre-seeds the registry with curated skills published by OpenAI at [github.com/openai/skills](https://github.com/openai/skills).
>
> *Based on an official public source. This does not indicate direct participation by OpenAI in the AI Registry.*

## What this repo contains

Skill approvals for all skills found under `skills/.curated/` in the [openai/skills](https://github.com/openai/skills) repository. The single approval file uses a glob source path (`skills/.curated/*`) so newly curated skills are picked up automatically on the next registry consolidation.

See the [Vendor Guide](https://github.com/eclipsefdn-ai-registry/ai-registry-core#vendor-guide) in the central repository for how vendor repos work, how to add approvals, and how validation runs.
